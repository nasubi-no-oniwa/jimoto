# 地元の最強

市町村の**本物の形**でぶつかり合う、全自動の1対1。明治22年（1889年）から今までの市町村・区（なくなった町村も）16,737が出場できる。
同じ組み合わせ・同じ向き・同じ政策なら、どの端末でも必ず同じ結果になる。

## あそびかた
- 2つの市町村をえらぶ（漢字・ひらがなで検索。「現存」「〇年 〇〇へ」の札つき）
- 向きを45度ずつ8方向から決める
- 政策カードを3枚まで（予算10。人口5万人未満は交付金で予算が増える）
- はっけよい！ 先に65％を失った方の負け。60秒たったら残りが多い方の勝ち
- 結果の画像をXに投稿できる（#地元の最強）
- あいことば対戦：お互いにこっそり決めて同時に公開。2人とも同じモード（政策あり／なし）で準備OKになったら開始。3人目からは観戦

## 強さ
体力＝面積、勢い＝人口、速さ＝人口密度、かたさ＝形のまとまり、鋭さ＝形のトゲ（かたさ・鋭さは全市町村の中の順位）

## ファイルの中身

## データ
- 形：「国土数値情報（行政区域データ）」（国土交通省）をもとに、ROIS-DS人文学オープンデータ共同利用センター「歴史的行政区域データセットβ版」（CC BY 4.0）を加工して作成
- 人口：総務省統計局「国勢調査」（e-Stat）1980〜2020年。それより前になくなった町村は、1980年のまわりの人口密度とその時代の全国人口から出した推定
- 読みがな：日本郵便「郵便番号データ」をもとに作成（見つからないものは推定）
- 効果音：Kenney「Impact Sounds」（CC0）　BGM：自作
